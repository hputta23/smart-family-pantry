Smart Family Pantry — Master Build Prompt 1. Project Identity: App name: Smart Family Pantry. Platform: React Native (iOS + Android) with Expo. 2. Core Mental Model: Grocery logistics and price intelligence tool for families. Goals: Reduce time, reduce money, reduce nutritional drift. 3. Design System: "digital kitchen board" aesthetic. Warm off-whites, slate typography, amber and teal accents. 4. Navigation: Tab 1: List (The Fridge Board), Tab 2: Scan (Receipt Camera), Tab 3: Pantry, Tab 4: Budget, Tab 5: Settings. 5. Key Features: Real-time list sync, Price engine (confidence scoring), Receipt OCR pipeline, Pantry inventory (predictive restocking), Budget tracking, Trip optimization. 6. Offline Mode: Local caching with sync on reconnect. 7. Real-Time Sync: WebSocket-based delta updates.
